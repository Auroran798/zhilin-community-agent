智邻管家（北京物业智能体）免 Docker 运行操作说明
==================================================

适用环境：Windows 10/11 64 位（x64/amd64）

本版本已经自带便携 Python 3.13 和全部运行依赖。
对方电脑不需要安装 Docker，也不需要安装 Python、数据库或向量库。


一、解压文件
------------

1. 把“智邻管家_北京物业智能体_免Docker最终提交版.zip”保存到电脑。
2. 右键 ZIP，选择“全部解压缩”。
3. 点击“提取”。
4. 不要直接在 ZIP 压缩包里运行程序。


二、启动系统
------------

最简单的方法：

1. 打开解压后的文件夹。
2. 双击“一键启动-Windows.bat”。
3. 第一次启动会初始化数据库、Demo 数据和知识索引，通常需要 2—8 分钟。
4. 启动完成后，浏览器会自动打开：http://127.0.0.1:8501

如果双击 BAT 后被安全软件阻止，可以在文件夹地址栏输入 powershell，按回车，然后执行：

    powershell -ExecutionPolicy Bypass -File ".\一键启动-Windows.ps1"

启动窗口显示“启动成功”后即可使用。

四、检查是否运行正常
--------------------

双击“运行检查-Windows.bat”。

也可以在 PowerShell 中执行：

    powershell -ExecutionPolicy Bypass -File ".\运行检查.ps1"

最后显示下面内容即为正常：

    PASS：便携 Python、API、离线 RAG、默认北京模式、数据边界和 Web 均正常。


五、停止系统
------------

双击“停止服务-Windows.bat”。

也可以在 PowerShell 中执行：

    powershell -ExecutionPolicy Bypass -File ".\停止服务-Windows.ps1"

停止后演示数据会保留在 runtime_data 文件夹中。下次重新启动时可以继续使用。


六、端口被占用
--------------

如果默认的 8000 或 8501 端口被占用，在 PowerShell 中执行：

    powershell -ExecutionPolicy Bypass -File ".\一键启动-Windows.ps1" -ApiPort 18080 -WebPort 18501

此时页面地址为：

    http://127.0.0.1:18501

检查命令为：

    powershell -ExecutionPolicy Bypass -File ".\运行检查.ps1" -ApiPort 18080 -WebPort 18501


七、常见问题
------------

1. Windows 提示“是否允许访问网络”：程序只监听本机 127.0.0.1，可允许专用网络访问，不需要开放公用网络。
2. 第一次启动很慢：正在建立离线知识索引，请等待，不要关闭窗口。
3. 页面没有自动打开：手动访问 http://127.0.0.1:8501 。
4. 安全软件拦截便携 Python：将完整解压目录加入可信范围后重试；不要只复制单个 exe。
5. 移动文件夹后无法运行：必须整体移动根目录，不能只移动 runtime、source 或脚本中的某一部分。
6. 电脑是 ARM 或 32 位 Windows：本提交包没有验证，不属于支持范围。

1. 没有接入真实物业公司、居民、账单或工单数据。

5. 系统不能自动发布公告、减免费用、修改真实账单或认定法律责任。
