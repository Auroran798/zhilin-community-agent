# Stage 6 category-mapping evaluation

`category_mapping_legacy_rule_generated.jsonl` is retained only as historical
evidence. Its expected labels were generated by the same rule system being
evaluated, so it is not a valid gold set and is rejected by the evaluator.

Run `python -m scripts.stage6_pipeline prepare-evaluation` to create a blind
annotation worksheet. At least 300 rows must then be independently reviewed.
For every accepted row, fill `expected_category`, `reviewer`, `reviewed_at` and
set `review_status` to `human_reviewed`. Save the reviewed rows as
`category_mapping_gold.jsonl`; model predictions must never be copied into the
gold labels.
