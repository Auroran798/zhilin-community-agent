# RAG

Stage 2 uses file-hash deduplication, parsers for PDF/DOCX/TXT/Markdown/HTML, deterministic chunk IDs, governed multilingual metadata, and a persistent Chroma collection when `chromadb` is installed. Retrieval applies role/community/jurisdiction/version/review filters before BM25 and dense recall, fuses ranks with RRF, guarantees a representative candidate from each authorised document, and optionally calls a `/rerank`-compatible multilingual reranker. The deterministic hashing embedding and lexical reranker are offline fallbacks intended for demos/tests, not a semantic production model.

The fallback has an audited Chinese/English property-domain glossary for retrieval-only expansion. It never alters the user's question, creates facts, or bypasses jurisdiction filtering. Explicit mentions of conflicting jurisdictions are refused before retrieval. Every evidence item exposes BM25, dense, RRF and reranker diagnostics. `/ready` and evaluation reports expose a quality profile; formal claims are disabled unless a real embedding provider and external reranker are configured.
