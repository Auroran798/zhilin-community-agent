# 02 业务流程与状态机

## 一、居民报修工单闭环

```mermaid
flowchart TD
  A[居民自然语言输入] --> B[意图识别: 报修]
  B --> C[字段抽取]
  C --> D{关键字段缺失?}
  D -- 是 --> E[最少必要追问] --> C
  D -- 否 --> F[风险判断]
  F --> G{高风险事件?}
  G -- 是 --> H[提示应急处置并人工升级]
  G -- 否 --> I[展示摘要与处置路径]
  I --> J{居民确认?}
  J -- 否 --> E
  J -- 是 --> K[创建工单: 待受理]
  K --> L[客服受理]
  L --> M[派单]
  M --> N[维修处理]
  N --> O{需配件?}
  O -- 是 --> P[等待配件] --> N
  O -- 否 --> Q[待居民确认]
  Q --> R{居民确认完工?}
  R -- 否 --> N
  R -- 是 --> S[居民评价]
  S --> T[已完成] --> U[已关闭]
```

关键字段为位置、故障现象、联系方式；设备、影响范围和图片按类别或风险补充。电梯困人、火灾或疑似火灾、燃气泄漏、配电冒烟或焦味、人身冲突、重大财产损失、责任争议不得自动建单后静默处理，必须提示紧急联系方式并人工升级。

## 二、费用查询与核查

```mermaid
flowchart TD
  A[费用查询请求] --> B[身份校验]
  B --> C{房屋绑定有效?}
  C -- 否 --> X[拒绝访问并记录日志]
  C -- 是 --> D[查询模拟账单与缴费记录]
  D --> E{需要对比?}
  E -- 是 --> F[对比账单]
  E -- 否 --> G[检索收费依据]
  F --> G
  G --> H[解释差异并引用依据]
  H --> I{依据充分且可解释?}
  I -- 是 --> J[返回只读结果]
  I -- 否 --> K[创建费用核查申请]
  K --> L[人工处理]
```

系统不得修改金额、减免、退款、扣款或修改缴费状态。

## 三、公告草稿与人工审核

```mermaid
flowchart TD
  A[输入公告需求] --> B[补全公告字段]
  B --> C[生成正式版草稿]
  C --> D[生成群公告短版]
  D --> E{字段完整性检查通过?}
  E -- 否 --> B
  E -- 是 --> F[提交人工审核]
  F --> G{审核通过?}
  G -- 否 --> H[退回修改] --> B
  G -- 是 --> I[人工发布]
  I --> J[已发布公告]
```

智能体只能创建或修改草稿；发布始终为人工动作，不提供自动发布路径。

## 四、巡检异常整改

```mermaid
flowchart TD
  A[文字或照片上报] --> B[异常提取]
  B --> C[风险等级判断]
  C --> D{高风险?}
  D -- 是 --> E[人工升级与应急处置]
  D -- 否 --> F[创建整改工单]
  E --> F
  F --> G[分配整改人员]
  G --> H[提交整改结果]
  H --> I[管理人员复查]
  I --> J{复查通过?}
  J -- 否 --> G
  J -- 是 --> K[关闭整改工单]
```

重大安全整改关闭须人工审批；照片仅作为附件引用，阶段 0 不进行实时视频分析。

## 五、工单状态机

```mermaid
stateDiagram-v2
  [*] --> 待补充信息
  待补充信息 --> 待受理: 信息完整且确认
  待补充信息 --> 已取消: 居民撤回
  待受理 --> 已受理: 客服受理
  待受理 --> 已取消: 居民撤回或重复确认
  已受理 --> 已派单: 分配处理人
  已派单 --> 处理中: 处理人接单
  处理中 --> 等待配件: 缺少配件
  等待配件 --> 处理中: 配件到位
  处理中 --> 待居民确认: 提交处理结果
  待居民确认 --> 处理中: 居民不确认
  待居民确认 --> 已完成: 居民确认或人工核验
  已完成 --> 已关闭: 评价完成或评价期结束
  已完成 --> 处理中: 复开经人工核验
  已取消 --> [*]
  已关闭 --> [*]
```

禁止：跳过已受理或已派单直接处理；从已关闭改回任何状态；非分配人员进入处理中；未完成居民确认或人工核验即关闭；高风险工单未经人工升级标记而关闭。
