# 06 待确认事项

阶段 0 采用保守默认方案，以下问题不阻塞文档交付。

| 待确认问题 | 当前默认方案 | 影响模块 | 最晚确认阶段 |
|---|---|---|---|
| 是否有合作物业单位 | 暂无，使用虚构小区和公开/自编规范 | 范围、知识库 | 阶段1 |
| 是否能获得脱敏真实工单 | 默认不能；只按字典生成模拟数据 | 数据、评测 | 阶段1 |
| 第一版使用哪种大模型 | Provider 抽象，暂不绑定 | Agent、配置 | 阶段2 |
| 知识文档从哪里获取 | 授权/公开资料并记录版本来源 | RAG | 阶段2 |
| 是否需要房屋绑定模拟登录 | 默认提供模拟绑定和授权校验 | 认证、权限 | 阶段1 |
| 是否支持上传图片 | 默认支持受控附件引用，不做视觉识别 | API、巡检 | 阶段1 |
| 是否区分维修部门 | 默认按类别映射，部门清单待定 | 派单、权限 | 阶段1 |
| 工单优先级规则 | P1-紧急、P2-高、P3-常规；高风险必人工 | Domain、Agent | 阶段1 |
| SLA 时限 | 默认仅记录时点，不承诺具体时限 | 看板、工单 | 阶段1 |
| 账单字段范围 | 默认物业费/停车费/水电费及账期状态 | 数据、费用 | 阶段1 |
| 演示环境部署位置 | 默认本地单机演示 | 部署 | 阶段5 |
| 最终团队人数和分工 | 默认3-5人，业务/后端/Agent/前端分工 | 计划、Issue | 阶段1 |
