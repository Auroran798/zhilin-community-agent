# 05 风险与人工审核

| 风险 | 可能后果 | 等级 | 预防措施 | 检测方式 | 降级措施 | 人工介入 |
|---|---|---|---|---|---|---|
| 居民隐私泄露 | 信息暴露、投诉 | 高 | 资源归属校验、字段脱敏、最小权限 | 越权测试、访问审计 | 拒绝并隐藏资源存在性 | 是 |
| 越权查询 | 他户账单/工单泄露 | 高 | 用户-房屋绑定、任务分配校验 | 授权负向测试 | 拒绝、告知合法渠道 | 是（反复异常） |
| 提示词注入 | 绕过审核或泄露数据 | 高 | 指令分层、工具白名单、上下文隔离 | 注入回归集 | 不调用工具、转人工 | 是（写操作） |
| 虚构收费标准 | 错误收费结论 | 高 | 仅基于有效 RAG 证据回答 | 引用完整率检查 | 明示依据不足、创建核查 | 是 |
| 虚构维修承诺 | 服务纠纷 | 中 | 禁止承诺具体到场/修复时间 | 回复规则扫描 | 使用“以工单/人工为准” | 否/争议时是 |
| 高风险事件漏报 | 人身或财产损失 | 严重 | 关键词+模型双重规则、宁可多升 | 高风险召回测试 | 立即人工升级与应急提示 | 是，强制 |
| 重复创建工单 | 重复派工 | 中 | 幂等键、相似未结单提醒 | 重复率监控 | 合并/人工核验 | 是（合并） |
| 工具调用失败 | 业务中断或假成功 | 中 | 超时、重试、确认回执 | 调用指标与错误日志 | 明示失败，不声称完成 | 是（持续失败） |
| 工单非法流转 | 数据失真 | 高 | 状态机和角色守卫 | 转换验证、审计 | 拒绝并保留原状态 | 是（例外） |
| 过期制度引用 | 错误规则 | 中 | 生效/失效日期过滤 | 检索过滤测试 | 提示过期、转人工 | 是 |
| 公告未经审核发布 | 错误传播 | 高 | 仅草稿工具，无自动发布接口 | 发布审计、权限测试 | 阻断发布 | 是，强制 |
| 账单被错误修改 | 财务纠纷 | 严重 | 工具不提供金额/状态写入 | API 契约与负向测试 | 阻断、审计、人工核查 | 是，强制 |

## 强制人工边界

电梯困人、火灾或疑似火灾、燃气泄漏、配电冒烟/异味/焦味、人身冲突、重大财产损失、责任争议必须人工升级。正式公告发布、费用减免或退款、修改账单、删除业务记录、改变用户权限、关闭重大安全整改必须经人工审批。
