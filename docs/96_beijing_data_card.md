## 隐私与真实性

生成器不创建真实姓名、电话号码、身份证号码、精确住址或真实物业公司名称/经营事实。实体使用合成标识符和虚构社区范围。数据文件与 manifest 均标明 `synthetic=true`、`real_property_authorization=false`、`contains_real_personal_data=false`。

禁止把这些数据描述为：

- 真实居民数据；
- 真实账单或收费结果；
- 真实工单、投诉、巡检或设备现状；
- 真实物业公司的绩效、经营或责任事实。

## 允许用途

- 产品流程演示；
- RBAC、写操作、幂等和审计回归；
- RAG 当前小区制度的受控展示；
- Dashboard、类别和季节趋势的 UI 演示；
- 在不接触真实个人信息前提下的课程和研究复现。

## 局限与后续授权

该数据不能证明真实社区的分布、收费合理性、SLA 达成率、设备健康度或居民满意度。未来接入真实数据前，需要物业公司书面授权、数据处理协议、最小化字段方案、脱敏/访问控制、留存与删除政策、安全评估和独立验收；真实数据必须与 `DEMO_SYNTHETIC` 物理或逻辑隔离。
