# Stage 7 权限与安全

| 操作 | 允许角色 | 阻断方式 |
| --- | --- | --- |
| 查看他人账单/房屋 | 无 | Binding 对象级校验，403 |
| 派单 | 客服、经理 | RBAC + 人工 API/MCP 确认 |
| 审批/发布公告 | 经理 | 审批状态机；发布不自动暴露 MCP |
| 修改金额、退款、减免 | 无 | 根本不注册工具/路由 |
| 提交巡检 | 被分派维修/巡检人员 | 任务归属校验 |
| 关闭 critical/high 整改 | 经理 | 复查端点 RBAC，AI 无关闭路径 |
| 修改 Public Real | 无 | 不提供写路由或写工具 |

所有派单、状态变化、审批、发布、复核处理、巡检、整改、设备创建及调度均记入审计。Harness 仅记录脱敏输入/输出。
