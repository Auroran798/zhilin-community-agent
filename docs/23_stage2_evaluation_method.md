# 阶段 2 离线评测方法

评测集在 `evals/rag/dataset.jsonl`，覆盖物业合同、规约、装修、停车、收费、公共区域、宠物、消防、电梯/火灾/燃气/停水/停电/极端天气、维修、报修、投诉、公告与维修资金，并包含越权、无依据、过期和跨小区样本。

指标：Recall@k（前 k 条证据是否含期望标题/来源）、引用完整率（回答样本是否均有来源 URL、标题和版本）、拒答率（无依据与注入样本被拒绝的比例）、平均/95 分位延迟。运行 `python evals/rag/run.py` 会输出 JSON 结果与 Markdown 报告；该报告是当前本地语料与当前配置的快照，不应替代上线前人工抽检。
